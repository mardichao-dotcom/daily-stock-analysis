# 標準輸出範例 — 關鍵價截圖判讀

> 用途:`keyprice-read` skill 的**判讀行為範本**。
> 來源:2026-09-15 實際判讀批次(節錄 11 檔)。
> ★ 重點不只是格式,更是下面這**五種判斷行為**。

---

## 為什麼這份範例重要

格式可以照抄規格文件,但「**遇到不確定該怎麼辦**」只能靠範例示範。
這份的每一條備註,都在示範判讀員的天職:**忠實記錄、不確定就標記、絕不自己猜**。

### 五種必須複製的判斷行為

**1. 遇到矛盾,兩個數字都記 + 標需複核(不自己選一個)**
- `COHR`:文字寫「小內撐 344」,但右軸目測約 386 → 照文字記 344、備註寫明不一致
- `SMCI`:文字寫「內撐 26」,但右軸目測約 24.2 → 同樣處理

**2. 主動提出「這可能是別的東西」**
- `華通`:92.0 和 89.8 兩條線很接近,但之間看不出色塊 → 暫記兩條線,
  備註寫「若其實是區域,改成 89.8–92.0」

**3. 說明「為什麼這個不排除」(預先回答複核者的疑問)**
- `PWR`:「起漲買盤訂單塊」→ 備註說明它含「訂單塊」會歸訂單塊;
  排除清單只有「起漲K」,不含它

**4. 記錄忽略了什麼(讓複核者知道「有看到、只是照規則不記」)**
- 每檔備註都寫「XXX、XXX 為 SMA,已忽略」
- 「1 個橘圈已忽略」「起漲K 方框依規則忽略」

**5. 規則本身模糊就反問**
- `COHR`:文字是「小內撐 344」,而「小」剛好也是合法形容詞
  → 備註問「需複核:『小』要不要拆到形容詞欄?」

### 最高原則

> **不確定就標記、不要猜。**
